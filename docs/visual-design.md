# 官网视觉与排版原则

## 在栏目间保留一个固定的阅读起点

从 Tasks 切到 Contribute，读者应当在同一个位置读到新标题。两页采用共建页的版心、顶部留白和标题尺度。标题从左上角起排，右栏的图示和控件在标题起点以下展开。英文大字沿顶边压低字高，中文按宋体字面单独定字号，两种语言共用版面坐标。

栏目入口使用 `.section-landing` 和 `.section-title`。有图示的首屏使用 `.section-hero`，在正文前留一道版心宽的细线。桌面左右并排，手机先读标题和说明，再看图。两页采用相同的首屏高度，长文本或放大字号时允许内容自然撑开。未来的榜单可沿用标题起点，把整行留给结果表。

首页由全画幅金字塔带入任务展示。首页首屏有自己的构图，往下滚动依靠图片、标题和留白衔接。

## 用留白、卡片和局部细线表达关系

- 同一段阅读路径共用底色。首页共建邀请的两边对齐任务展示的版心，圆角长卡之外仍能看到连续的页面背景。
- 把一项行动、一组可比较的选项或一份可扫描的名录收在一起。三个科学目标是同级卡片，每页十题共用一个列表面板。卡片最多内嵌一层，更细的信息用字号、字重和间距区分。
- 面板使用 `--panel-radius`，按钮和输入框使用较小的 `--control-radius`。矩阵外框可以带圆角，内部网格仍然连续，便于跟踪行列。
- 先用节间留白区分主题。短线适合对应明确的条目，例如“团队与合作信息”下面一行行的定义。整行细线留给栏目首屏进入正文等重要转折。

## 夜间品牌色

日间沿用米白纸面与浅绿页栏。夜间顶栏和页脚使用同一块不透明的深松绿（`#202e28`），配灰绿色文字和标志。深色按钮的默认、悬停和选中状态使用各自的实色底，文字仍清楚可读。绿色承担导航和结构，蓝与金标注领域、层级或证据。金字塔、分布容器和档案夹的色彩由各自材质决定。

## 双语断行与校样

展示标题使用现有衬线字，介绍和题目摘要按短段落平衡行长，元数据沿公共列对齐。先调整列宽，再检查字号。英文句尾尽量保留完整语组，中文避免单个汉字连着句号落到末行。首页全名可以按构图主动分行。窄屏的矩阵可以横向滚动，学科名按完整单词排版。

发布前在同一窗口来回切换 Tasks 与 Contribute，核对标题左上角和首屏底线，再试三个分布标签。分别查看中英文、日夜主题、手机、平板和宽屏。重点看委员会的一句话说明、较长的科学目标和领域名、提交入口与任务摘要，最后用键盘检查矩阵和名录的焦点。
