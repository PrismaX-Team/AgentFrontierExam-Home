# 官网视觉与排版原则

## 在栏目间保留一个固定的阅读起点

从 Tasks 切到 Contribute，读者应当在同一个位置读到新标题。两页采用共建页的版心、顶部留白和标题尺度。桌面上第一行标题的可见字顶、任务分布标签的字顶和共建档案夹题注的字顶落在同一条水平线上。英文大字沿顶边压低字高，中文按宋体字面单独定字号。

栏目入口使用 `.section-landing` 和 `.section-title`。有图示的首屏使用 `.section-hero`，在正文前留一道版心宽的细线。桌面左右并排，手机先读标题和说明，再看图。两页采用相同的首屏高度，长文本或放大字号时允许内容自然撑开。未来的榜单可沿用标题起点，把整行留给结果表。

首页是这个字号系统的例外。全画幅金字塔与英文全名共同决定首屏的比例，往下滚动依靠图片、标题和留白衔接。委员会栏按可见底边对齐末行标题、说明文字与播放图标，按钮周围留有可点击的空间。手机上前后翻阅按钮靠近委员照片。

## 各内页共用三级标题

| 层次 | 字号变量 | 对照位置 |
| --- | --- | --- |
| 页面主标题 | `--page-title-size` | Tasks、Contribute、任务详情、任务包指南和署名页，在同一视口与语言下使用同一字号 |
| 章节标题 | `--section-heading-size` | Field × task type matrix、Task briefs 和 What would count as success? |
| 条目标题 | `--entry-heading-size` | 任务列表的题名与共建页的 Scientific workflows 等科研目标 |

各级同时共用行高和字形比例。窄屏英文让三级字号一起随版心收放，保留主次和长科学词组所需的空间。中文沿用宋体的独立尺度。评审时在页面实际加载字库后，比较可见字形的上下边缘。行框、衬线字的纵向变换和 SVG 按钮的点击范围都可能带来光学偏差。

## 用留白、卡片和局部细线表达关系

- 同一段阅读路径共用底色。首页共建邀请的两边对齐任务展示的版心，圆角长卡之外仍能看到连续的页面背景。
- 把一项行动、一组可比较的选项或一份可扫描的名录收在一起。三个科学目标是同级卡片，每页十题共用一个列表面板。卡片最多内嵌一层，更细的信息用字号、字重和间距区分。
- 面板使用 `--panel-radius`，按钮和输入框使用较小的 `--control-radius`。矩阵外框可以带圆角，内部网格仍然连续，便于跟踪行列。
- 先用节间留白区分主题。短线适合对应明确的条目，例如“团队与合作信息”下面一行行的定义。整行细线留给栏目首屏进入正文等重要转折。
- 任务列表面板内的细线贯穿题名、领域和层级三列，标出一条完整记录。矩阵标题只承担阅读层次，右侧箭头单独负责展开与收起。

## 夜间品牌色

日间沿用米白纸面与浅绿页栏。夜间阅读区使用平整的炭黑底，卡片、表头与输入框分别指定不透明底色。较亮的低饱和色用于文字与焦点，大面积用色保持深沉。金字塔与分布容器保留磨砂材质。选色参考了 Material 关于暗底上降低强调色饱和度的建议。普通正文按 WCAG AA 的 4.5∶1 下限逐对核算。[Material 暗色设计](https://developer.android.com/design/ui/wear/guides/m2-5/styles/color) · [W3C 正文对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

| 次要说明 | `#bab9ad` | `#191b19` | 8.77∶1 |

## 双语断行与校样

展示标题使用现有衬线字，介绍和题目摘要按短段落平衡行长，元数据沿公共列对齐。先调整列宽，再检查字号。英文句尾尽量保留完整语组，中文避免单个汉字连着句号落到末行。首页全名可以按构图主动分行。窄屏的矩阵可以横向滚动，学科名按完整单词排版。

任务详情标题可用的宽度取决于旁边是否有配图。标题沿用栏目字号，给长科学名称留出换行宽度。连字符可作为复合词的自然折行点。手机目录将领域与任务类型上下排列，层级对齐在右侧。

发布前在同一窗口来回切换 Tasks 与 Contribute，核对标题字顶和首屏底线，再逐项操作三个分布标签。总数与当前分类共用一个读数位置。鼠标移开恢复总数，键盘焦点和触屏点选也能读到分类与题数。完整名称始终列在图例里。分别查看中英文、日夜主题、手机、平板和宽屏，核对长词、播放与暂停图标、矩阵折叠和键盘焦点。
